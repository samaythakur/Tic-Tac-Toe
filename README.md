# Tic-Tac-Toe

# Project Overview
-Developed a GUI-based Tic-Tac-Toe game using Python and Tkinter.
-Implemented turn-based gameplay logic with dynamic player switching between X and O.
-Designed an interactive graphical interface using Tkinter buttons and grid layout management.
-Added automatic win-condition checking for rows, columns, and diagonals.
-Implemented draw detection and automatic game reset functionality.
-Demonstrated concepts of event-driven programming, conditional logic, and game state management in Python.
